블로그 정기 유지보수를 수행하세요.

## 1. 태그 정합성
`tag-curator` 스킬 실행. 결과 요약.

## 2. temp 폴더 처리
`blog/temp/`에 미정리 글이 있으면 사용자에게 알리고 `/organize-temp` 진행 여부 확인.

## 3. 폴더 지도 검증
- `blog/`의 실제 폴더 목록과 `blog/CLAUDE.md`의 폴더 지도 표를 대조
- 표에 없는 폴더 발견 시 사용자에게 보고 후 표에 추가

## 4. 고립 노트 탐지
- `blog/**/*.md`(단, `index.md`·`_tags.md`·`_*.md` 제외) 중 어디서도 `[[wikilink]]`로 참조되지 않고, 본문에도 wikilink가 0개인 글 목록
- 상위 5개만 보고 (전체 나열은 시끄러움). `link-weaver` 적용 후보로 제안

## 5. 보안 점검 (샘플링)
- 최근 수정된 `publish: true` 글 중 5개를 무작위로 골라
- vault CLAUDE.md "블로그 글 작업 전 보안 체크리스트"에 위배되는 패턴이 있는지 grep
  - 회사명·실제 도메인·AWS Account ID·이메일·credential 패턴
- 발견 시 보고 (자동 수정 금지)

## 6. 보고
각 단계의 결과를 한 화면 안에 요약. 사용자가 추가 액션을 요청하면 그때 진행.
